# Wine Quality Prediction Pipeline

| | Deskripsi |
| ----------- | ----------- |
| Dataset | [Red Wine Quality (winequality-red.csv)](https://www.kaggle.com/datasets/uciml/red-wine-quality-cortez-et-al-2009). Dataset ini terdiri dari 1.599 baris data, memiliki 11 fitur numerik (`fixed acidity`, `volatile acidity`, `citric acid`, `residual sugar`, `chlorides`, `free sulfur dioxide`, `total sulfur dioxide`, `density`, `pH`, `sulphates`, `alcohol`) sebagai atribut prediktor. dan 1 fitur target `quality` dengan rentang nilai [3, 4, 5, 6, 7, 8] yang merepresentasikan kelas skor kualitas wine. |
| Masalah | Penentuan kualitas anggur yang dilakukan secara tradisional dan manual tentunya akan membutuhkan biaya yang mahal dan proses yang lambat. Untuk mengatasi permasalahan tersebut diperlukan adanya sistem otomatisasi dalam memprediksi tingkat kualitas anggur berdasarkan sifat kimia fisiknya secara efisien dan otomatis. Masalah ini diselesaikan menggunakan pendekatan supervised multiclass classification untuk memprediksi kecenderungan skor kualitas wine berdasarkan input 11 properti fisikokimia. Model tidak menentukan kualitas wine secara absolut, melainkan memprediksi berdasarkan pola statistik pada dataset. |
| Solusi machine learning | Membangun **End-to-End MLOps Pipeline** dengan menggunakan  library TensorFlow Extended (TFX) yang mencakup pemrosesan data, validasi skema, hyperparameter tuning, pelatihan model, evaluasi, hingga deployment model. |
| Metode pengolahan | Pemrosesan fitur dengan menggunakan komponen `Transform (tensorflow_transform)` yang digunakan untuk melakukan normalisasi z-score yaitu *mean* dan *variance scaling* pada seluruh fitur numerik agar memilki skala yang terstandarisasi. |
| Arsitektur model | Model Deep Neural Network (DNN) dibangun menggunakan hyperparameter optimal hasil tuning (`best_hyperparameters.txt`), terdiri dari Hidden Layer 1 (128 units, ReLU), Hidden Layer 2 (16 units, ReLU), dan Output Layer `Dense(6)` (Softmax). Model dioptimasi menggunakan Adam Optimizer dengan *learning rate* sebesar 0.01. |
| Metrik evaluasi | Metrik evaluasi menggunakan metrik `SparseCategoricalCrossentropy` sebagai loss function utama, serta metrik `SparseCategoricalAccuracy` untuk mengukur tingkat presisi klasifikasi target. |
| Performa model | Model dievaluasi menggunakan Evaluator dengan metrik kriteria `SparseCategoricalAccuracy` mencapai minimal `0.3 (value_threshold)` dan peningkatan performa dibanding baseline sebesar `0.0001 (change_threshold)`. Setelah dilakukan training dan dievaluasi menggunakan Evaluator (TFMA), model berhasil mencapai nilai `SparseCategoricalAccuracy` sebesar 0.553 atau 55.3%. Nilai ini berhasil melampaui kriteria batas minimal `value_threshold` dan peningkatan dibanding baseline, sehingga model dinyatakan *blessed* dan diekspor oleh Pusher ke direktori serving. |
